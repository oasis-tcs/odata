OData EDM model structure

This document lists all EDM model elements, their attributes and relationships. It categorizes the element's attributes into basic and model attributes and describes their semantics in detail. It is generated from a JSON file that is based on the OASIS OData CSDL XML Representation Version 4.02 specification, and adds the details about allowed values, symbolic references and constraints for elements and attributes.

Model attributes can be resolved paths to other model elements and sometimes just a reference to a model element.
